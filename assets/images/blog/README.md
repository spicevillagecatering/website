# Blog Images

Place your blog post images here.

## Required Images

- `blog-1.jpg` - First blog post image
- `blog-2.jpg` - Second blog post image  
- `blog-3.jpg` - Third blog post image

## Image Specifications

- **Format**: JPG or PNG
- **Size**: Recommended 800x600px or 1200x900px
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Keep under 500KB per image

## Featured Menu Images

Also add these to `assets/images/menu/`:
- `featured-1.jpg` - Signature Dishes
- `featured-2.jpg` - Traditional Favorites
- `featured-3.jpg` - Festive Specials
