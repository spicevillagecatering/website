# Image Upload Guide

## Folder Structure

### `/assets/images/logo/`
Place your **Spice Village Catering logo** here:
- File name: `logo.png` or `logo.jpg`
- Recommended size: 200x80px (or similar aspect ratio)
- Format: PNG (with transparency) or JPG

## Image Specifications

- **Format**: JPG or PNG
- **Size**: Recommended 800x600px or 1200x900px
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Keep under 500KB per image for fast loading
- **Quality**: High quality, well-lit food photography

## After Uploading

Once you've uploaded your images, the website will automatically use them. The image paths are already configured in the HTML.
