=====================================================================
  TIPS
=====================================================================

FORMAT
  Use JPG for photos (better compression, smaller file size)
  Use PNG only for logos and images that need transparent backgrounds

FILE SIZE
  Keep each photo under 500 KB
  Next.js converts images to WebP automatically and resizes on the fly
  Smaller originals = faster builds and lower AWS bandwidth costs

NAMING
  Use EXACTLY the filenames listed above (lowercase, hyphens, .jpg)
  Filenames must match what is written in each component file

HOW TO REPLACE A PLACEHOLDER
  1. Drop the image file into this folder  (public/images/)
  2. Open the matching component in app/components/
  3. Find the comment that says  REPLACE with:
  4. Swap the placeholder <div> with the <Image> code shown in the comment

EXAMPLE
  Before (placeholder):
    <div className="img-ph" style={{ background: '...' }}>
      <span>Hero Banner Image</span>
    </div>

  After (real image):
    <Image
      src="/images/hero-banner.jpg"
      alt="Spice Village Catering"
      fill
      priority
      className="object-cover object-center"
    />
